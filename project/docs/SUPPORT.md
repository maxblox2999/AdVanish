# Completion

| SDK path | Automatic Close requirement |
| --- | --- |
| Google rewarded | Matching original SDK reward callback |
| Google native-video interstitial/app-open | Real end events for the captured items; no mixed web phase |
| MAX through AppLovin | Matching reward and validated adapter-to-creative ownership |
| AppLovin X view | Current visible SDK Close view and unchanged, enabled tap registration |
| Other mediation adapters | No reward-based Close adapter without proven ownership |

Automatic mode enables acceleration, supported input and Close. Manual mode waits for the button and never activates Close. Rewards and server validation remain controlled by the SDK and game.
