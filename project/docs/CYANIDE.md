# Cyanide

Cyanide QuickLoader runs JavaScript through a SpringBoard session. It exposes no loader for game-process frameworks, which AdVanish requires. No Cyanide QuickLoader build is available.

The [jailed injection build](../BUILD.md#ipa-injection) is a separate per-app option. Physical-device compatibility with Cyanide is unverified.
